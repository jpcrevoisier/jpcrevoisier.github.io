Aide : format du code JS
Votre code reçoit canvas (300×150 par défaut, redimensionnable via canvas.width / canvas.height) et ctx (contexte 2D). Dessinez sur ctx. Le code est ré-exécuté à chaque dépôt (idéal pour date/heure/aléatoire). await est supporté. Vous pouvez aussi retourner un canvas ou une chaîne dataURL pour surcharger le rendu.

Exemple : 
canvas.width = 220;
canvas.height = 90;
ctx.fillStyle = '#2563eb';
ctx.fillRect(0, 0, 220, 90);
ctx.fillStyle = '#fff';
ctx.font = '16px sans-serif';
ctx.fillText('Le ' + new Date().toLocaleDateString(), 12, 50);
